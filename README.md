# 2D to 3D Image Converter

A web application that converts 2D images into proper 3D models using **TripoSR** — a state-of-the-art open-source AI model by Stability AI and Tripo AI.

## Demo

Upload a single front-facing photo → get a full 3D GLB model with front, back, and sides generated by AI.

---

## What's New (Our Upgrades)

### 3D Reconstruction Engine
- **Replaced MiDaS depth estimation** with **TripoSR** (Stability AI) — generates a true 3D mesh from a single image, not just a depth-warped flat surface
- TripoSR runs fully on **CPU** — no GPU required
- Integrated **rembg (u2net)** for AI-based background removal before 3D reconstruction — cleaner, tighter meshes

### Backend
- FastAPI backend updated to support TripoSR inference pipeline
- Background removal runs automatically on every upload
- Persistent output directory — generated GLB files are served directly via `/download/{filename}`
- Added `/debug/files` endpoint for troubleshooting
- Optional back image support in the API

### Frontend (3D Viewer)
- Replaced the fake browser-side depth estimation with a **real GLB loader** using Three.js `GLTFLoader`
- Model is loaded directly from the backend output
- Auto-centering and scaling of the loaded mesh
- Axes helper (X/Y/Z) and grid floor for spatial reference
- Studio-style grey background
- Orbit controls — drag to rotate, scroll to zoom, right-click to pan
- No auto-rotation — model stays still until you interact

### UI
- Added optional **Back Image** upload slot
- Model info panel (type, quality, file size)
- Download GLB button wired to actual backend file

## Installation

### Prerequisites
- Python 3.8+
- Node.js 18+
- Git

### Backend Setup

```bash
git clone https://github.com/Atharvashind/2d-to-3d-image-converter-.git
cd 2d-to-3d-image-converter-

# Create virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac

# Install dependencies
pip install -r requirements.txt
pip install rembg onnxruntime omegaconf einops huggingface-hub imageio xatlas moderngl

# Start backend (downloads TripoSR model ~1.7GB on first run)
python start_backend.py
```

Backend runs at `http://localhost:8000`

### Frontend Setup

```bash
cd 2d-to-3d-converter
npm install --legacy-peer-deps
npm run dev
```

Frontend runs at `http://localhost:3000`

## Usage

1. Open `http://localhost:3000`
2. Upload a front-facing image (JPG, PNG, WEBP)
3. Optionally upload a back image
4. Select quality (Low = faster, High = more detail)
5. Click **Convert to 3D**
6. Wait for processing (first run ~5-10 min on CPU, subsequent runs faster)
7. Rotate the model in the viewer, then download the GLB

---

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/health` | Service health check |
| POST | `/convert` | Convert image to 3D (multipart: `file`, `back_file`, `model_type`, `quality`) |
| GET | `/download/{filename}` | Download generated GLB |
| GET | `/debug/files` | List generated files |

---

## Performance Notes

- **CPU only**: ~5-10 minutes per conversion at medium quality
- **With GPU (CUDA)**: Under 30 seconds
- Model weights (~1.7GB) are downloaded once and cached in `~/.cache/huggingface`
- 8GB+ RAM recommended
